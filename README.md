<h1> Jogo do número secreto </h1>
<h2> Sobre </h2>
<p>Projeto desenvolvido durante os cursos de Lógica de Programação da Alura, no qual criamos um jogo interativo de adivinhação de números. 
  O objetivo é descobrir um número secreto entre 1 e 50, recebendo dicas a cada tentativa, indicando se o número escolhido é maior ou menor que o correto. 
  Ao acertar, o jogo informa a quantidade de tentativas realizadas. O projeto também conta com recurso de síntese de voz, que faz a leitura automática das instruções 
  e mensagens sempre que o enunciado é atualizado! </p>
